

การรัน Script Python บน GitHub และให้ตัว Script เซฟไฟล์กลับเข้ามาเก็บไว้ใน Repository ของ GitHub โดยอัตโนมัติ สามารถทำได้ง่ายๆ ผ่านฟีเจอร์ที่เรียกว่า **GitHub Actions** ครับ

วิธีทำมีขั้นตอนดังนี้:

---

### ขั้นตอนที่ 1: เตรียมไฟล์ใน Repository ของคุณ

สมมติว่าคุณอัปโหลดไฟล์เหล่านี้ขึ้น GitHub แล้ว:

1. **`main.py`** (หรือชื่อไฟล์ Python ของคุณ) — ตัวอย่างโค้ดที่สร้างไฟล์ผลลัพธ์ เช่น ไฟล์ `output.txt` หรือไฟล์ CSV:
```python
# ตัวอย่างโค้ดใน main.py ที่สร้างไฟล์ขึ้นมาใหม่
with open("output.txt", "w", encoding="utf-8") as f:
    f.write("Hello from GitHub Actions! File saved automatically.")
print("Saved output.txt successfully.")

```



---

### ขั้นตอนที่ 2: ตั้งค่าสิทธิ์ Workflow (Permissions)

เพื่อให้ GitHub Actions สามารถเขียนและ push ไฟล์กลับเข้า Repository ได้:

1. ไปที่หน้า Repository ของคุณบนเว็บ GitHub
2. คลิกที่แท็บ **Settings** > เลือก **Actions** > **General**
3. เลื่อนลงมาที่หัวข้อ **Workflow permissions**
4. ติ๊กเลือกที่ **Read and write permissions** แล้วกด **Save**

---

### ขั้นตอนที่ 3: สร้างไฟล์ Workflow ตั้งค่า GitHub Actions

1. ที่หน้า repository ของคุณ ไปที่แท็บ **Add file** -> **Create new file**
2. ตั้งชื่อไฟล์พาธเป็น: `.github/workflows/run-script.yml`
3. วางโค้ด YAML ด้านล่างนี้ลงไป:

```yaml
name: Run Python Script and Save File

on:
  push:
    branches: [ "main" ] # ทำงานทุกครั้งที่มีการ push โค้ดขึ้น branch main
  # schedule:
  #   - cron: '0 0 * * *' # เปิดบรรทัดนี้ถ้าต้องการให้รันอัตโนมัติทุกๆ วัน (เวลาเที่ยงคืน)

permissions:
  contents: write # ให้สิทธิ์ Action แก้ไขและบันทึกไฟล์กลับเข้า repo

jobs:
  run-python:
    runs-on: ubuntu-latest
    steps:
      # 1. ดึงโค้ดจาก Repository มาที่ตัวรัน (Runner)
      - name: Checkout repository
        uses: actions/checkout@v4

      # 2. ติดตั้ง Python
      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: '3.10'

      # 3. ติดตั้ง Library เพิ่มเติม (ถ้ามี)
      - name: Install dependencies
        run: |
          python -m pip install --upgrade pip
          if [ -f requirements.txt ]; then pip install -r requirements.txt; fi

      # 4. รันไฟล์ Python ของคุณ
      - name: Run script.py
        run: python main.py

      # 5. สั่ง Commit และ Push ไฟล์ที่ถูกสร้างขึ้นกลับเข้า GitHub
      - name: Commit and push changes
        run: |
          git config --global user.name "github-actions[bot]"
          git config --global user.email "41898282+github-actions[bot]@users.noreply.github.com"
          
          # เช็คว่ามีไฟล์ใหม่หรือไฟล์ถูกแก้ไขไหม
          git status
          
          # ระบุชื่อไฟล์ที่ต้องการให้เซฟกลับเข้า Repo (สามารถเปลี่ยน output.txt เป็นชื่ออื่น หรือใช้ dấu * เช่น data/* ได้)
          git add output.txt 
          
          # ทำการcommit (หากไม่มีไฟล์เปลี่ยน จะไม่ทำการ commit ให้ error)
          git diff --quiet && git diff --staged --quiet || git commit -m "Auto-generated file from Python script [skip ci]"
          
          # ส่งไฟล์ขึ้น GitHub
          git push

```

4. กดปุ่ม **Commit changes...** ด้านบนขวาเพื่อบันทึกไฟล์

---

### สรุปการทำงาน

* ทุกครั้งที่คุณ **Push** โค้ดขึ้นไป (หรือตั้งเวลาด้วย Cron Job) GitHub จะจำลองเครื่องคอมพิวเตอร์เสมือนขึ้นมา
* ดึงโค้ด Python ของคุณไปรัน
* เมื่อ Python สร้างไฟล์เสร็จ (เช่น `output.txt`) ขั้นตอน Git ใน Workflow จะทำการ **Commit และ Push** ไฟล์นั้นกลับมาไว้ใน Repository ของคุณโดยอัตโนมัติ
